# 기특해 개인정보 처리 안내 초안

> 출시용 개인정보처리방침 URL에 옮기기 전 운영자 검토가 필요한 초안

## 처리하는 정보

- 사용자가 작성한 한 줄 기록
- AI 요청 보호를 위해 일방향 해시한 접속 식별값
- Vercel이 서비스 운영 과정에서 처리하는 접속 IP와 요청 메타데이터

## 처리 목적과 흐름

- 한 줄 기록과 선택된 동물 정보는 맞춤형 칭찬 문구 생성 목적으로 Vercel 서버를 거쳐 OpenAI API에 전송
- 기록 원문과 생성된 칭찬은 사용자 기기의 앱 저장소에 보관
- 별도 회원 DB나 서버 기록 DB는 운영하지 않음
- Vercel 애플리케이션 로그에 기록 원문과 OpenAI API 키를 남기지 않음
- OpenAI 요청은 `store: false`로 전송

## 보관과 삭제

- 사용자는 앱에서 개별 기록 또는 전체 기록 삭제 가능
- 앱 삭제나 기기 저장소 초기화 시 기기에 저장된 기록 삭제 가능
- OpenAI는 악용 방지 로그를 기본적으로 최대 30일 보관할 수 있음

## 외부 처리 사업자

- Vercel: API 호스팅과 요청 처리
- OpenAI: 입력 분석과 한 줄 칭찬 생성

## 운영 전 확인

- 실제 고객 문의 이메일과 시행일 추가
- 앱인토스 콘솔에 공개 가능한 HTTPS 개인정보처리방침 URL 등록
- OpenAI 데이터 정책 변경 시 보관 기간 문구 재검토

OpenAI 데이터 처리 참고: https://platform.openai.com/docs/models/default-usage-policies-by-endpoint
