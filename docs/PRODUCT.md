# 기특해

## 한 줄 정의

오늘 잘한 일을 한 줄 남기면 그림판에서 튀어나온 동물 친구가 엉성한 칭찬 도장을 찍어주는 작은 일기

## 해결하려는 감정

대단한 성취가 없었다고 느끼는 하루에도 사소한 잘한 일을 발견하고 인정받는 경험

## 핵심 사용자 흐름

1. 오늘 잘한 일 한 줄 입력
2. 짧은 칭찬 코멘트 확인
3. 도장 모션 확인
4. 달력에 쌓인 기록 열람
5. 해금된 동물로 채워지는 가족사진 확인
6. 날짜를 눌러 기록과 코멘트 다시 보기

## MVP 범위

- 하루 한 기록, 최대 80자
- AI가 글의 맥락과 동물 말투를 함께 반영한 한 줄 코멘트
- 같은 동물 말투 안에서 다시 받을 때 달라지는 칭찬
- 애매하거나 장난스러운 입력도 거절하지 않고 상황에 맞는 반응과 도장 제공
- AI 지연·오류·미설정 시 앱 내부 동물 코멘트로 자동 대체
- 그림판에서 마우스로 그린 듯한 5종 동물 캐릭터
- 누적 날짜에 따른 동물 해금과 해금된 동물의 랜덤 등장
- 처음 만난 동물이 앱 시작 시 건네는 짧은 첫인사
- 누적 일수마다 빈자리가 채워지는 동물 가족사진
- 오늘 기록·칭찬 달력 탭 분리
- 날짜를 누르면 기록, 동물 코멘트, 확대 도장을 보여주는 상세 팝업
- 개별·전체 기록 삭제와 삭제 후에도 유지되는 동물 해금
- 앱인토스 네이티브 Storage 저장
- 브라우저 개발 환경에서는 localStorage 대체

## 의도적 제외

- 회원가입과 토스 로그인
- 서버 DB와 여러 기기 동기화
- 연속 출석 초기화와 실패 표시
- 공개 피드와 친구 기능
- 광고와 리워드

AI 호출은 별도 서버를 경유하며 OpenAI 키를 미니앱에 포함하지 않음. 기록 원문은 기기에 저장하고, AI 코멘트를 만들 때 입력한 한 줄만 서버로 전송

## 챌린지 적합성

- 작은 기능: 하루 한 줄과 도장 하나
- 완결된 경험: 작성, 칭찬, 수집
- 웃음 요소: 날짜마다 바뀌는 하찮은 동물 친구와 과장된 도장 모션
- 재방문 요소: 하루 단위 기록, 동물 해금, 랜덤 도장 수집

## 출품 문구 초안

- 한 줄 소개: 오늘 잘한 일을 한 줄 남기면 그림판 동물 친구가 엉성한 칭찬 도장을 찍어줘요
- 주제 연관성: 설거지, 물 마시기처럼 하찮아 보이는 일도 발견해 과하게 칭찬해 주는 작은 일기예요. 거창한 목표나 실패 기록 없이 한 줄과 도장만으로 피식 웃으며 하루를 마무리하는 완결된 경험을 만들었어요
